## AfriDam AI × TECHFEAST 2026

A standalone, mobile-first skin-analysis demonstration built with Next.js for the TECHFEAST 2026 event.

The application provides an interactive experience where visitors can capture or upload a facial image and request AI-powered skin analysis through the AfriDam AI backend.

Features

1. Mobile-first, responsive interface.

2. Live camera capture and image upload.

3. Image preview and user consent flow.

4. Server-side API integration.

5. Image type and size validation.

6. Dynamic diagnostic results based on actual API responses.

7. No fabricated skin measurements or confidence scores.

## Technology Stack

1. Next.js

2. React

3. TypeScript

4. Tailwind CSS

Development

```bash
npm install
npm run dev
```
